# Security reporting

GitHub private vulnerability reporting was not enabled when checked on
2026-11-01. Maintainers must enable it and verify that the reporting control is
available before describing it as an active channel.

Once enabled, use **Security → Advisories → Report a vulnerability** in
[this repository](https://github.com/zawasystem/duo_rail_kit/security/advisories).
If that control is not available, this reporting channel has not been
established; do not post vulnerability details or secrets in a public issue.
No alternative public contact address is designated here.

Include the affected version or commit, platform and SDK versions, impact, and
a minimal reproduction, without tokens, keys, or account data. Layout bugs
without security impact can use the issue tracker when it is available.
