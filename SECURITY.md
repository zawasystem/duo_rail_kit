# Security reporting

The source repository is public; no version has been published on pub.dev.
Include the affected commit or package version, platform and SDK versions,
impact, and a minimal reproduction in a
security report. Remove tokens, private keys, account data, and other secrets.

GitHub private vulnerability reporting was not enabled when checked on
2026-11-01. Maintainers must enable it and verify that the reporting control is
available before describing it as an active reporting channel.

Once enabled, use **Security → Advisories → Report a vulnerability** in
[this repository](https://github.com/zawasystem/duo_rail_kit/security/advisories)
to send a private report. If that control is not available, this reporting
channel has not been established; do not post vulnerability details or secrets
in a public issue. No alternative public contact address is designated here.

General layout bugs without security impact can use the issue tracker when it
is available.
